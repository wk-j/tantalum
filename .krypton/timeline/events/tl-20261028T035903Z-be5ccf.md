# ออกแบบ tantalum เป็น CLI ภาษา Go บน macOS: เก็บ secret เข้ารหัส AES-256-GCM โดยกุญแจอยู่ใน login Keychain ส่วน agent ใช้ secret ผ่าน `tantalum run -s NAME -- cmd` ซึ่งใส่ค่าใน environment และปิดค่าทุกตัวใน output เป็น [REDACTED:NAME] โดยไม่มีคำสั่งให้ agent อ่านค่า

## Evidence
Vault: ~/.tantalum/vault.json, AES-256-GCM. Key: a random 256-bit key in the macOS login Keychain (service `tantalum`, account = vault directory). `run`: starts a command with secrets in its environment and pipes its stdout/stderr through a redactor that replaces every vault value with `[REDACTED:NAME]`. Does **not** protect against a deliberately hostile agent.

## Rationale
เป้าหมายคือไม่ให้ค่า secret เข้าไปอยู่ใน context ของ agent, log ของผู้ให้บริการโมเดล หรือ transcript; การใช้ Keychain ทำให้ agent ไม่ต้องพิมพ์รหัสผ่านทุกครั้ง และ CLI ใช้ได้กับ agent ทุกตัวที่รัน shell ได้

## Impact
ป้องกันการรั่วโดยไม่ตั้งใจเท่านั้น ไม่ป้องกัน agent ที่ตั้งใจขโมยค่า เพราะรันในสิทธิ์ผู้ใช้เดียวกัน (แปลงค่าก่อนพิมพ์ หรืออ่านกุญแจด้วย security find-generic-password ได้) ถ้าต้องกันกรณีนั้นต้องแยก OS user หรือ sandbox
