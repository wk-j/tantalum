# เพิ่ม `ta reveal [-e ENV] [-c] NAME`: ถามระบบด้วย LocalAuthentication (policy LAPolicyDeviceOwnerAuthentication: Touch ID ถ้ามี ไม่มีก็ Apple Watch หรือรหัสผ่านเครื่อง) ก่อนอ่านค่า แล้วเขียนค่าไป /dev/tty หรือ clipboard ที่ติดป้าย org.nspasteboard.ConcealedType และล้างหลัง 45 วินาทีถ้ายังไม่มีการคัดลอกอื่น; ไม่เขียนค่าออก stdout/stderr; ต้องใช้ cgo; เป็นข้อยกเว้นของ rail ใน ADR 0001 ที่บันทึกเป็น ADR 0005

## Evidence
ta reveal [-e ENV] [-c] NAME — for humans: after Touch ID (or an Apple Watch or the login password) shows the value on the terminal, or with -c copies it to the clipboard and clears the clipboard after 45 seconds; never writes it to stdout

## Rationale
agent ตอบหน้าต่างยืนยันตัวตนของระบบไม่ได้ จึงยังรักษาเป้าหมายของ ADR 0001 ที่ไม่ให้ค่าเข้า context ของ agent; ใช้ policy ที่ยอมรับรหัสผ่านด้วยเพราะเครื่อง Mac Studio ของผู้ใช้ไม่มีอุปกรณ์ Touch ID จับคู่อยู่ (ตรวจด้วย canEvaluatePolicy ได้ 'Biometric accessory is not paired'); ไม่เขียน stdout เพราะ harness ของ agent เก็บ stdout ไว้

## Impact
การ build ต้องมี Xcode command line tools (cgo); rails test โหลดไฟล์ cgo ด้วย FakeImportC และมี rail ใหม่ 3 ข้อ
