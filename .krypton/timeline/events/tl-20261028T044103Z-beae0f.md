# เพิ่มไฟล์ `.tantalum.json` (`{"project": "NAME"}`) ใน repo: ทุกคำสั่งของ ta หาไฟล์ที่ใกล้ที่สุดจาก directory ปัจจุบันขึ้นไป แล้วใช้ vault `$TANTALUM_HOME/projects/NAME` ที่มีกุญแจ Keychain ของตัวเอง; `ta init -p NAME` เขียนไฟล์และสร้างหรือใช้ vault เดิม; `ta list`, `ta serve` และหน้าเว็บแสดงว่ากำลังใช้ vault ไหน

## Evidence
Every command run in that directory or below uses the project named by the nearest `.tantalum.json` ({"project": "api"}); outside any project, commands use the default vault in `~/.tantalum`. A `.tantalum.json` that cannot be parsed stops every command instead of falling back to the default vault.

## Rationale
ไฟล์เก็บแค่ชื่อ project จึง commit ได้ และใช้ได้ทุกเครื่องโดยไม่ผูกกับ path ของใคร; ไฟล์ที่อ่านไม่ได้ต้องหยุดทำงาน เพราะการใช้ vault default แทนแบบเงียบ ๆ อาจทำให้อ่านหรือเขียน secret ผิด project

## Impact
TANTALUM_HOME เปลี่ยนความหมายเป็นที่เก็บ vault default และโฟลเดอร์ projects/; run ปิดค่าเฉพาะ vault ที่ใช้อยู่ ไม่ปิดค่าของ project อื่น; ดูหลาย project ใน Web UI ต้องเปิด ta serve หลายตัวคนละ port
