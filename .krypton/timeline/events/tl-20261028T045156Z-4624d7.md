# เลิกใช้ `.tantalum.json` และ `ta init -p` แล้วเลือก vault จาก directory ของ git repository ที่รันคำสั่งอยู่: vault อยู่ที่ `$TANTALUM_HOME/projects/<ชื่อโฟลเดอร์>-<hash ของ path>`; subdirectory และทุก git worktree ใช้ vault ของ checkout หลัก; path ผ่าน symlink หรือตัวพิมพ์เล็ก-ใหญ่ต่างกันได้ vault เดียวกัน (ใช้ F_GETPATH ของ macOS); นอก git repository ใช้ vault default

## Evidence
Inside a git repository, every command uses that repository's own vault, $TANTALUM_HOME/projects/NAME-HASH, keyed by the repository directory (all worktrees share it). Elsewhere commands use the default vault in $TANTALUM_HOME.

## Rationale
ผู้ใช้ไม่ต้องการตั้งชื่อ project เอง ใช้ root ของ git repository เป็น key เพราะเป็นขอบเขต project ที่ชัด และให้ worktree ใช้ vault เดียวกับ checkout หลัก เพราะ agent หลาย lane มักทำงานคนละ worktree ของ repo เดียวกัน

## Impact
clone ใหม่หรือการย้าย/เปลี่ยนชื่อโฟลเดอร์ repo จะได้ vault ใหม่ที่ว่าง vault เก่าค้างใน projects/; ไฟล์ .tantalum.json ที่เคยสร้างไว้ไม่มีผลแล้ว
