# เพิ่มคำสั่ง `ta serve` เป็น web server ในตัว (Go net/http + หน้าเว็บฝังใน binary) ฟังที่ 127.0.0.1:7340 เท่านั้น ใช้ token ใหม่ทุกครั้งที่เปิด ส่งผ่าน URL fragment และ API ทำได้แค่ดูรายชื่อ เพิ่ม/แทนค่า และลบ secret โดยไม่มี endpoint ใดคืนค่า secret

## Evidence
ta serve [-addr HOST:PORT] — web UI for humans to add, replace and delete secrets (default 127.0.0.1:7340, loopback only). It never shows a value: no endpoint returns one. Requests whose `Host` or `Origin` is not the server itself are rejected.

## Rationale
ทุก process ในเครื่อง รวมถึง agent เรียก localhost ได้ ถ้า API คืนค่า secret ได้ ข้อดีหลักของ tantalum ที่ว่า agent ไม่เห็นค่าจะหายไป จึงทำให้เขียนได้อย่างเดียว และตรวจ Host/Origin เพื่อกันเว็บอื่นกับ DNS rebinding

## Impact
คนจัดการ secret ผ่านเบราว์เซอร์ได้ แต่ดูค่าเดิมจาก UI ไม่ได้; ถ้า token หลุด ผู้ถือ token เพิ่ม/แทน/ลบ secret ได้ แต่อ่านค่าไม่ได้
