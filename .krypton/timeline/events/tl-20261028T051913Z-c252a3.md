# หน้าเว็บ ta serve เปลี่ยนจากแท็บ environment เป็นตาราง secret × environment พร้อมช่องค้นหา, เพิ่ม secret หลาย environment พร้อมกัน, แทนค่า/ลบทีละช่อง, คัดลอกคำสั่ง ta run, เปลี่ยนชื่อ/ลบ secret ทุก environment, คัดลอก/เปลี่ยนชื่อ/ลบ environment และนำเข้าไฟล์ .env พร้อมตัวอย่างก่อนนำเข้า; API เพิ่ม /api/envs/{env}/copy|rename, DELETE /api/envs/{env}, /api/names/{name}/rename และ DELETE /api/names/{name}; ยังไม่มีปุ่มดูค่า ตาม ADR 0003

## Evidence
The page is a table of every secret name against every environment, so a secret missing from an environment shows as an empty `+` cell. No value is ever shown: no endpoint returns one, and copies and renames move values inside the vault only.

## Rationale
ADR 0004 ห้ามดึงค่าข้าม environment ช่องว่างในตารางจึงบอกได้ทันทีว่าคำสั่งไหนจะไม่สำเร็จใน environment ไหน; การคัดลอกและเปลี่ยนชื่อทำใน server ค่าจึงไม่ผ่านเบราว์เซอร์; การนำเข้า .env แยกค่าในเบราว์เซอร์แล้วส่งผ่าน PUT เดิม ค่าเข้า vault ทางเดียวที่ rail ของ ADR 0001 อนุญาต

## Impact
rails_test.go เพิ่ม route ใหม่ในรายการที่ตรวจ guard และตรวจว่าไม่มีค่าหลุด; ADR 0003 และ 0004 แก้ข้อความให้ตรงกับหน้าเว็บใหม่
