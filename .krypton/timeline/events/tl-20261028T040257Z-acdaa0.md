# เปลี่ยนชื่อคำสั่งจาก `tantalum` เป็น `ta` (สัญลักษณ์ธาตุของ tantalum) ตามที่ผู้ใช้บอกว่าชื่อยาวเกินไป โดยย้ายโค้ดไปที่ `cmd/ta` และติดตั้งด้วย `go install ./cmd/ta`; ชื่อโปรเจกต์, `~/.tantalum`, `TANTALUM_HOME` และ Keychain service `tantalum` คงเดิม

## Evidence
The command line name is too long

## Rationale
`ta` สั้นที่สุดที่ยังสื่อถึงชื่อโปรเจกต์ และตรวจแล้วไม่ชนกับคำสั่ง, alias หรือ function ที่มีในเครื่อง; ชื่อภายในที่คนไม่ต้องพิมพ์บ่อยคงเดิมเพื่อให้ยังรู้ว่าเป็นของ tantalum

## Impact
คนและ agent พิมพ์ `ta run -s NAME -- cmd` แทน `tantalum run ...`; ข้อความ error ขึ้นต้นด้วย `ta:`
