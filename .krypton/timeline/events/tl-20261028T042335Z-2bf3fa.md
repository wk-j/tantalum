# ตีความ "multiple env" เป็นการแบ่ง secret เป็นกลุ่มชื่อ environment (เช่น dev, prod) ใช้ flag `-e ENV` กับ set/rm/run (ไม่ระบุ = `default`), `ta list` แสดงทุก environment, web UI มีแท็บแยก environment และ API เปลี่ยนเป็น `/api/secrets/{env}/{name}`; vault เปลี่ยนเป็น format version 2 โดย vault version 1 เดิมยังอ่านได้และย้ายเข้า `default`

## Evidence
-e ENV picks an environment: a named set of secrets such as dev or prod (default "default"). An environment exists while it holds secrets. Vaults created before environments existed (file "version": 1) keep working: their secrets load as environment `default`, and the next change rewrites the file as version 2.

## Rationale
ชื่อ secret เดียวกันต้องมีค่าต่างกันได้ตาม environment; การไม่มีการดึงค่าข้าม environment อัตโนมัติทำให้ agent ไม่เผลอใช้ค่าของ environment ผิดตัว; การเพิ่ม version ทำให้ ta รุ่นเก่าที่อ่าน version 2 ไม่เข้าใจหยุดพร้อม error แทนที่จะเขียนทับจนข้อมูลหาย

## Impact
ข้อความ redaction เปลี่ยนเป็น [REDACTED:ENV/NAME]; ผู้ใช้มี vault version 1 ที่ ~/.tantalum และ ~/go/bin/ta รุ่นเก่า ต้อง go install ./cmd/ta ใหม่ เพราะรุ่นเก่าอ่าน vault หลังถูกเขียนเป็น version 2 ไม่ได้
